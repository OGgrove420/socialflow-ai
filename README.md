# SocialFlow AI

AI social-media content planning SaaS by Conscious Mind Concepts (Pty) Ltd, South Africa.

## stack

- next.js 15 (app router) + react 19 + typescript
- supabase (managed postgres + auth) — later milestone
- ai provider (tbd) — later milestone
- vercel hosting

## local setup

1. `npm install`
2. `npm run dev` → http://localhost:3000

## deploy

push to github, import repo in vercel. no secrets in git — env vars go in vercel project settings.
